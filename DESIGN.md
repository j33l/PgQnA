# Design Guidelines

## Colors

- **Primary Color:** `#615DF2`
- **Background:** `#FFFFFF`
- **Text:** `#1F2937`
- **Muted Text:** `#6B7280`
- **Border:** `#E5E7EB`
- **Success:** `#16A34A`
- **Error:** `#DC2626`

## UI Principles

- Keep the interface clean, minimal, and modern.
- Use the primary color for buttons, links, active states, and key highlights.
- Maintain consistent spacing, typography, and component styles.
- Prioritize readability, accessibility, and responsive layouts.
- Use subtle borders, rounded corners, and light shadows where appropriate.
- Provide clear hover, focus, active, loading, and disabled states.

## Typography

- Use a clean sans-serif font.
- Establish a clear hierarchy for headings, body text, and labels.
- Keep text readable and avoid unnecessary visual clutter.

## Components

- Use consistent styles for buttons, inputs, cards, dialogs, and navigation.
- Use rounded corners consistently.
- Ensure interactive elements have clear visual feedback.

## Responsive Design

- Keep layouts flexible and content easy to navigate across devices.
